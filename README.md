# AI Mystery Room — CaseFile

A responsive, static mystery-investigation game built with HTML, CSS, and vanilla JavaScript.

## Features
- Three fictional mystery cases
- Evidence logs and suspect selection
- Feedback and solution explanations
- Responsive dark investigation-themed interface
- No build tools, dependencies, or backend required

## Run locally
Open `index.html` in a browser.

## Deploy using GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site; the URL appears in the Pages section.

## Important
This is a newly recreated starter project based on the concept discussed. It is **not** the original Emergent source code, is not connected to an AI API or database, and uses fictional cases with browser-side answer logic.
